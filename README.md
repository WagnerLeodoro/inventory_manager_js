# Projeto API controle de estoque

- [ ] Criar a pasta do projeto com o nome stock_express
- [ ] Iniciar um novo projeto node ```npm init -y```
- [ ] Instalar a biblioteca express ```npm install express```
- [ ] Criar o arquivo server.js

## Requisitos Funcionais
- [ ] Deve ser possível cadastrar um novo produto
- [ ] Todo produto deve ser cadastrado com letras minúsculas
- [ ] Deve ser possível atualizar um produto existente
- [ ] Deve ser possível pesquisar um produto existente a partir do seu id
- [ ] Deve ser possível pesquisar um produto existente a partir do seu nome
- [ ] Deve ser possível deletar um produto a partir do seu id
- [ ] Não deve ser possível cadastrar um produto com o mesmo nome

## Requisitos não funcionais
- [ ] O sistema deve ser estruturado em camadas
- [ ] Os endpoints da aplicação deve seguir o padrão:
    * ```/api/produtos ``` - para rotas de produtos
    * ```/api/users ``` - para rotas de usuários
    * ```/api/vendas ``` - para rotas de vendas
    * ```/api/relatorios ``` - para rotas de relatório de vendas
